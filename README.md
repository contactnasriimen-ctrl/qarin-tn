# Qarin.tn — comparateur tunisien

Comparateur gratuit pour la Tunisie : **Internet** (fibre, VDSL, ADSL, box 4G/5G), **forfaits mobiles**, **vols**, **hôtels**, **assurance auto** et **location de voiture**.

- Site statique (HTML/CSS/JS, aucune dépendance), routage par hash.
- Filtres, tris, score qualité/prix, comparatif côte à côte (jusqu'à 3 offres), calendrier des prix pour les vols.
- Données dans `assets/data.js` — tarifs **indicatifs** à mettre à jour régulièrement.

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
npx serve .
```

## Déploiement

Publié automatiquement par GitHub Pages depuis la branche `main`.
